## 🔍 Où chercher vos emails :

### 1. Vérifier les SPAMS (PRIORITAIRE) ⚠️

**Gmail filtre souvent les emails de `onboarding@resend.dev`**

1. Ouvrez Gmail
2. Cliquez sur **"Courrier indésirable"** (ou "Spam") dans le menu de gauche
3. Cherchez les emails avec le sujet :
   - "Nouvelle demande d'abonnement - Pack Mensuel"
   - "Nouveau message de contact de..."
4. Si vous les trouvez :
   - Sélectionnez-les
   - Cliquez sur **"Ce n'est pas du spam"**
   - Cliquez sur **"Déplacer vers Boîte de réception"**

### 2. Vérifier "Tous les messages"

1. Dans Gmail, cliquez sur **"Tous les messages"** (ou "All Mail")
2. Cherchez les emails récents avec le sujet "Nouvelle demande d'abonnement"
3. Utilisez la recherche : `from:onboarding@resend.dev`

### 3. Rechercher dans Gmail

1. Dans la barre de recherche Gmail, tapez :
   ```
   from:onboarding@resend.dev
   ```
2. Ou cherchez :
   ```
   "Nouvelle demande d'abonnement"
   ```

### 4. Vérifier les filtres Gmail

1. Allez dans Gmail > **Paramètres** (roue dentée)
2. Cliquez sur **"Filtres et adresses bloquées"**
3. Vérifiez s'il y a des filtres qui déplacent automatiquement ces emails

### 5. Ajouter à vos contacts

Pour éviter que les futurs emails soient filtrés :

1. Ouvrez un email de `onboarding@resend.dev` (même s'il est dans les spams)
2. Cliquez sur l'adresse email
3. Cliquez sur **"Ajouter aux contacts"**

### 6. Vérifier dans Resend

1. Allez sur https://resend.com/emails
2. Cliquez sur un email dans la liste
3. Vous pouvez voir le contenu complet de l'email envoyé
4. Vérifiez le statut : "Delivered" = email livré
